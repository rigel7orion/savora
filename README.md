# 🍽️ Savora

**Savora** is a modern, responsive recipe discovery web app built to make deciding what to cook simple and enjoyable. Browse curated recipes, search by ingredients or dishes, filter by cuisine, difficulty and cooking time, and save your favorites locally.

## ✨ Features

* 🔎 **Recipe Search** — Search recipes by name, ingredients, cuisine, category, or description.
* 🏷️ **Smart Filtering** — Filter by category, cuisine, difficulty, cooking time, dietary tags, and more.
* ❤️ **Favorites** — Save and manage favorite recipes with browser `localStorage`.
* 🎙️ **Voice Search** — Search for recipes using the browser's Speech Recognition API.
* 🌙 **Dark Mode** — Light and dark themes with saved user preference.
* 📖 **Recipe Details** — View ingredients, servings, preparation time, cooking time, difficulty, and step-by-step instructions.
* 📱 **Responsive Design** — Optimized for desktop, tablet, and mobile screens.
* ♿ **Accessibility** — Includes semantic HTML, ARIA labels, keyboard-friendly controls, focus states, and reduced-motion support.
* 🎨 **Modern UI** — Custom typography, responsive recipe cards, animations, hover effects, and a warm food-focused visual design.

## 🚀 Getting Started

No build tools or dependencies are required.

1. Clone the repository.
2. Open `index.html` in your browser.
3. Start exploring recipes.

For the best experience, use a modern browser with JavaScript enabled.

## 🍳 Recipe Collection

Savora currently includes **12 curated recipes** spanning breakfast, lunch, dinner, desserts, vegetarian options, high-protein dishes, and multiple cuisines. Each recipe contains ingredients, cooking instructions, timing, difficulty, servings, tags, and imagery.

## 💾 Data & Storage

Recipe information is currently stored directly in the frontend JavaScript dataset. Favorites and theme preferences are persisted in the browser using `localStorage`, so no account or backend is required.

## 🎯 Purpose

Savora was designed as a clean frontend project focused on combining **good UI/UX with practical JavaScript functionality**, creating a recipe experience that feels more like a polished product than a static recipe collection.
